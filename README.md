## 1. Основы Git (Сохранение и синхронизация кода)

**Как получить код в первый раз:**
```bash
# Скачивает репозиторий на ваш компьютер
git clone <вставьте-ссылку-на-репозиторий>
cd <имя-папки>
```

**Повседневная работа (Как сохранять свои изменения):**
Каждый раз, когда вы меняете код в `main.py`, `models.py` или `database.py`, выполняйте эти три команды по порядку:
```bash
# 1. Подготовить все измененные файлы к сохранению
git add .

# 2. Создать снимок (сохранение) с понятным описанием
git commit -m "created enpoint for <something>"

# 3. Отправить ваши сохранения на GitHub/GitLab
git push
```

**Как получить код от товарищей по команде:**
```bash
# Скачивает последние изменения из удаленного репозитория
git fetch --all && git pull
```

Мы используем `uv`.

**Шаг 1: Установка необходимых библиотек**

## 4. Тестирование API

Вам не нужно писать фронтенд, чтобы проверить свой бэкенд. Есть три отличных способа протестировать API:

### Способ А: Swagger UI (Рекомендуемый и самый простой)
FastAPI автоматически создает красивый веб-интерфейс для тестирования.
1. Откройте браузер.
2. Перейдите по адресу: **[http://localhost:8000/docs](http://localhost:8000/docs)**
3. Нажмите на нужный эндпоинт (например, зеленый `POST /anime`).
4. Нажмите кнопку **"Try it out"**.
5. Заполните данные в формате JSON и нажмите **Execute**. Проверьте ответ сервера (Server response) ниже.

### Способ Б: Использование cURL (Для хакеров в терминале)
cURL позволяет отправлять запросы прямо из командной строки (откройте новое окно терминала).

* **Получить все аниме (GET):**
  ```bash
  curl -X GET http://localhost:8000/anime
  ```

* **Создать новое аниме (POST):**
  ```bash
  curl -X POST http://localhost:8000/anime \
       -H "Content-Type: application/json" \
       -d '{"title": "Bleach", "year": 2004, "episode_count": 366}'
  ```

### Способ В: Использование Postman (Профессиональный инструмент)
Postman — это популярная программа для тестирования API.
1. Откройте Postman и создайте новый запрос (New Request).
2. Выберите метод (например, `GET` или `POST`) в выпадающем меню слева.
3. Введите URL: `http://localhost:8000/anime`.
4. **Если это POST/PATCH запрос:**
   * Перейдите во вкладку **Body**.
   * Выберите **raw** и в выпадающем списке справа выберите **JSON**.
   * Вставьте ваш JSON (например, `{"title": "One Piece", "year": 1999, "episode_count": 1000}`).
5. Нажмите синюю кнопку **Send** и посмотрите результат в нижней части экрана.
